# Puertas CPE movil

App Expo para calcular puertas directamente desde movil en el portal CPE.

## Requisitos
- Node 18+
- Expo Go en el movil (Android o iOS)

## Ejecutar
```bash
cd mobile-app
npm install
npm start
```

## Uso
1. Abre Expo Go y escanea el QR.
2. Inicia sesion en el portal dentro de la app.
3. Pulsa `Ir Chapero`.
4. Introduce tu chapa y pulsa `Calcular`.

## Nota
En modo web (`npm run web`) no funciona el calculo real; usa Android/iOS.
